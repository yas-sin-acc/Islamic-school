# Madrasa System (React JS, no UI libraries)
1. Install Node.js, open this folder in a terminal
2. `npm install`
3. `npm run dev`  -> open the shown address

Logins: Male Director `admin` / `admin123`, Female Director `admin2` / `admin123` (change in Settings).
Teachers, finance employees and parents get their logins in their registration forms.
Optional login background photo: save it as `public/bg-madrasa.jpg`.
Data is saved in the browser (localStorage). Translations: `src/dict.js`.
Print any report/certificate/ID, and choose "Save as PDF" as the printer to get a PDF.
